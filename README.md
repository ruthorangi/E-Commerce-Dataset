# E-Commerce-Dataset
A Power BI dashboard project analyzing an online store performance.  
# Project Overview
This E commerce project uses data analysis and visualization techniques to examine online sales data. The dashboard helps identify the total sales, units sold, and total profit accrued over a certain period of time. The dashboard highlights store performance and stock by store location, and products sold.  
# Business Problem
The stakeholders of Orangi E Commerce need to understand how the store has been performing over the years and which areas need to be optimized for maximum output. This dashboard answers the following:
Which Year had the most sales and profit?
Which store is best performing?
How are the products performing? with data showing unit sold, total sales and total profit?
How is the stock concentration by store location?
# Tools Used
The dataset was cleaned and manipulated and transformed on the excel workbook and Power query, Power BI and DAX measure
